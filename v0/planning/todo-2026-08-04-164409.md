# Problems + fixes

## High priority

- No automated tests; CI releases without running lint, typecheck, or build.
  - Fix: add a pull-request validation job running npm ci, lint, typecheck, and build from v0/www.
  - Fix: add tests for validator failures, routes, Markdown transformations, and sorting/filtering.

- Missing image and image-list shortcode references silently disappear in production.
  - Example: @[image](typo) shows a development warning but renders nothing in production.
  - Fix: parse shortcode references during content validation and fail the build when a referenced key is absent.

## Medium priority

- Accessibility gaps: no skip link; heading hierarchy not validated.
  - Fix: add a “Skip to content” link and stable main-content target.
  - Fix: reject skipped Markdown heading levels during validation.

- Weak crawler and feed discovery: no sitemap, robots metadata, or RSS/Atom feed.
  - Fix: generate all three from the registry and content route helpers.

- Placeholder authors are publicly registered; their links point to example.com.
  - Fix: remove them before production, or isolate sample content behind an explicit demo mode.

- isNSFW appears on browse cards only; direct post pages lack a warning.
  - Fix: show the warning consistently on home, publication, and post pages; optionally blur covers and apply appropriate metadata.

## Low priority

- Generated dependency clutter: 55 UI components, while only the dialog module is imported by application code outside that directory.
  - Fix: delete unused UI modules, then prune their dependencies from package.json.

- Compiled Python bytecode is committed under v0/branding/generators/__pycache__.
  - Fix: remove the bytecode and add __pycache__/ and *.pyc to a root .gitignore.
