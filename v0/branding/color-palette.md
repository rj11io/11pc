# Color palette

Dark mode is the default visual theme for 11blog.

| Variable | Hex |
| --- | --- |
| `--background` | `#0A0A0A` |
| `--foreground` | `#FAFAFA` |
| `--primary` | `#2BC88F` |
| `--primary-foreground` | `#002C22` |
| `--secondary` | `#27272A` |
| `--muted` / `--accent` | `#262626` |
| `--muted-foreground` | `#A1A1A1` |
| `--accent-surface` | `#121C17` |
